# Condufy

App gamificada estilo Duolingo para preparar el examen teórico de conducir de la DGT (carnet B/coche y A/moto). Lecciones de teoría por tema + tests fieles al formato real del examen (30 preguntas, 3 opciones, imágenes, cronómetro de 30 min).

Un único archivo HTML/CSS/JS, sin build ni backend — todo el progreso se guarda en el navegador (`localStorage`).

Uso: abre `index.html` en el navegador, o entra a la versión publicada en GitHub Pages.
